## 1. "How I Create With AI" — build-in-public video

**Status:** Concept

**Format:** Short-form video (TikTok / Reels / Shorts / X)

### The message

A video about how I like to create using AI — specifically, that I use **agentic AI to
code** the app.

**Why coding is a great fit for AI:** The planning and prompting targets the agents at
local, well-defined tasks. The "creative control" the agent has lives entirely in the
*code it writes*, not in the *task it completes*. This flips AI's biggest weakness —
that it converges to the mean with its output — into a strength: converging to the mean
means the code follows best practices for the tasks we've defined. Average code style
executing a precisely specified task is exactly what you want.

**Why design stays human:** For design, I use a mainly human process — flipping the
narrative. AI does the planning and brainstorming; I do the design and output
generation myself. Design output demands a genuinely creative approach, which is a bad
task for AI's mode of operating. Where code benefits from convergence, design suffers
from it.

The split, in one line: **AI executes where convergence helps; humans create where
convergence hurts.**

### The package

The message is delivered over footage of the actual workflow:

- Me vibe coding the app with agentic AI (terminal, agents running, tasks completing)
- Me designing our pixel-art assets manually (Aseprite, sprite work, the garden coming
  together)

Showing the split visually makes the argument land, and the app is on screen the whole
time — it subtly advertises Rooted without the video ever feeling like an ad.
